# Last 30 Days Tech Trend Monitor

Based on [`github.com/mvanhorn/last30days-skill`](https://github.com/mvanhorn/last30days-skill).

## Scope

1. Tracks enterprise hardware discussions in `r/sysadmin`, `r/hardware`, and tech forums.
2. Identifies common device recalls, component vulnerability alerts, and emerging enterprise hardware standards (DDR5, PCIe Gen5 NVMe, Wi-Fi 7).
