# Humanizer Prose Skill

Based on [`github.com/blader/humanizer`](https://github.com/blader/humanizer).

## Guidelines

1. Strip clichéd AI buzzwords: *delve, testament, beacon, pivotal, overarching, tapestry*.
2. Write direct, conversational, professional technical prose.
3. Apply to AssetTrack user notifications, condition inspection logs, and repair tickets.
4. Keep errors empathetic, precise, and actionable.
