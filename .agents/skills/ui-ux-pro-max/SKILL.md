# UI UX Pro Max Skill

Based on [`github.com/nextlevelbuilder/ui-ux-pro-max-skill`](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill).

## Rules for AssetTrack

1. **Accessible Status Badges:**
   - Available: Emerald (`#059669`)
   - Assigned: Blue (`#2563EB`)
   - Under Repair: Amber (`#D97706`)
   - Retired / Scrapped: Slate (`#64748B`)
2. **Mobile Camera Scanning:** Provide clear, high-contrast camera viewfinder guides for `html5-qrcode` mobile QR scanner.
3. **Data Grids:** Ensure horizontal scrolling with sticky headers and pinned action columns for dense hardware inventory tables.
