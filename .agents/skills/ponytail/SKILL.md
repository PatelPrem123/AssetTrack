# Ponytail Senior Developer Assistant Skill

Based on [`github.com/DietrichGebert/ponytail`](https://github.com/DietrichGebert/ponytail).

## Core Principles

1. **Write Less Code:** Prefer simple, standard JavaScript/Node.js idioms over elaborate abstraction layers.
2. **KISS (Keep It Simple, Stupid):** Avoid premature generalization. Implement what the hardware lifecycle requires, nothing more.
3. **No Gratuitous Dependencies:** Use native capabilities (Zod, native Mongoose compound indexes) rather than bloated helper libraries.
4. **Pragmatic Refactoring:** Refactor code to be understandable at 2 AM by an on-call engineer.
