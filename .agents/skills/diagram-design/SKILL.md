# Technical Diagram Design Skill

Based on [`github.com/cathrynlavery/diagram-design`](https://github.com/cathrynlavery/diagram-design).

## Instructions

1. Use standard Mermaid syntax (`flowchart TD`, `sequenceDiagram`, `stateDiagram-v2`, `erDiagram`).
2. Always quote node labels with special characters (brackets, parentheses).
3. Diagram AssetTrack core workflows:
   - Hardware spec hierarchy (CPU -> RAM modules -> Storage drives).
   - Asset lifecycle state transitions (Purchased -> Available -> Assigned -> Under Repair -> Retired).
   - Chain of custody handovers and return condition inspections.
   - Component evolution and stock movement synchronization.
