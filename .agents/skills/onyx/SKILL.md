# Onyx Enterprise Search Integration

Based on [`github.com/onyx-dot-app/onyx`](https://github.com/onyx-dot-app/onyx).

## Scope

1. Integrates local RAG search over IT equipment user guides, hardware maintenance manuals, and vendor warranty contracts.
2. Answers technician questions regarding motherboard jumper layouts, maximum RAM expansion limits, and warranty claim procedures.
